Log in seconds

One comparable number

A limit that warns early

Students set a monthly limit. The dashboard bar turns green, amber, then red as they approach it.

Included

Questions colleges ask

Where is student data stored?

Only in the student's own browser (localStorage). Clearing browser data removes it.

Does it need an internet connection?

The pages load online, but the calculator and chat helper run in the browser without a server.

Can students use it on phones?

Yes. The layout is designed phone-first and grows to tablet and desktop.
